## 二、B 榜（按 step）

### Step1 —— Faster R-CNN 教师模型 / 首轮伪标签

| 脚本 | 作用 |
|:---|:---|
| `train.py` | **Faster R-CNN（ResNet50-FPN-v2）训练**，50 epoch，无验证 |
| `train2.py` | 续训 150 epoch + macro-F1 checkpointing（**跨图匹配缺陷**） |
| `annotate.py` | 伪标签生成（阈值 0.95），含置信度直方图（**未被消费**） |
| `eval.py` | F1/AP 评估（**手写左黎曼 AP，无 precision envelope**） |
| `check.py` | 环境与数据自检（**只检查前 10 个 XML 发现类别**） |
| `setup_env.py` | 创建 `26cnsoft` 环境（本地 wheel 装夜间版 torch） |

### Step2 —— 数据工程与伪标签配方

| 脚本 | 作用 |
|:---|:---|
| `infer.py` | 全量推理 → `raw_predictions.pkl`（不设阈值） |
| `gen_labels.py` | 多阈值伪标签 XML + `conf_map.json` + `split.json` |
| `train_exp.py` | 10 轮 8 组消融（**只跑完 3 组**） |
| `train_exp2.py` | 30 轮 8 组实验（AdamW + LinearLR + Cosine，patience 5；**只跑 TIER1**） |
| `divide.py` | 验证集重划分（`np.linspace` 30 张）+ `final_data/` 固化 |

### Step3 —— YOLO 切换与架构筛选

| 脚本 | 作用 |
|:---|:---|
| `train1.py` | 初版（**basename 冲突导致加权失效**；模型名拼错） |
| **`train1_1.py`** | **修正版（`{base}_{idx:05d}` 唯一命名，物理复制加权）** |
| `train1_2.py` | 续训（**基于日志的三路决策 + OOM 降 batch**） |

### Step4 —— 超参数调优

| 脚本 | 作用 |
|:---|:---|
| `train1.py` | 粗筛（8 组 = 2 模型 × 2 优化器 × 2 lr；**AdamW momentum=None bug**） |
| **`train1_1.py`** | **修正版（momentum=0.9 + amp=False + 日志解析式断点续传）** |
| `test.py` | 暴力扫描所有权重并重新验证（同时找 `weights/` 与 `train/weights/`） |

### Step5 —— PyTorch→Paddle 转换与首次提交

| 脚本 / 产物 | 作用 |
|:---|:---|
| `export.py` | PyTorch → ONNX(opset=12) → X2Paddle 双路径 |
| **`predict.py`** | **首次提交用（640 + 手写 NumPy NMS(0.45) + 面积 argmax）** |
| `tool/x2paddle_output/` | X2Paddle v1 产物（**动态 slice + 有 float32 cast**） |
| `tool/x2paddle_v2_output/` | X2Paddle v2 产物（**硬编码 slice + 无 cast，可用**） |
| `tool/test_submission_cpu.py` | 按竞赛规则在 CPU 上测试提交文件夹 |

### Step6 —— 速度优化（唯一达标的平台成绩）

| 脚本 | 作用 |
|:---|:---|
| `eval.py` | 本地 CPU 精度+速度评估（**image-scoped 正确匹配**） |
| `P1/predict.py` | **640 + 去 NMS**（复用 step5 模型，仅改后处理） |
| **`P2/predict.py`** | **512 + 去 NMS（最终提交）** |
| `P2/export_512.py` | 512 ONNX 导出 + X2Paddle + `os.walk` 兜底查找 + 写 `infer_cfg.yml` |
| `P2/convert_model.py` | **三级 tracing 级联**：`pdparams` → `paddle.jit.save` → `.pdmodel` |
| `P3/predict.py` | + TensorRT FP32（三级回退：TRT → GPU → CPU） |
| `P4/predict.py` | + Batch=2（闭包式 batch 累加器 + 失败回退单图） |

### Step7 —— HSV 规则标注 → 自举迭代 + 人工修正

| 脚本 | 作用 |
|:---|:---|
| `hsv.py` | **HSV 规则标注（失败的方案，2827/2827 全判为有火）** |
| `tool/init.py` | 种子构建（**"≥0.99 筛选"实际是全部 1275 张，因 XML 无 confidence 字段**） |
| `tool/train.py` | **通用训练脚本（硬编码超参；chdir 到数据集目录）** |
| `tool/gen.py` | 分层伪标签生成（5 档）+ `metadata.json` |
| `tool/merge.py` | 种子 + 新伪标签合并（**`new_c > 1.0` 是死分支**） |
| `tool/converge.py` | 收敛判定（**图片数口径**） |
| `tool/build4.py` | 整合全量标签 + 9 张人工修正 → `data4`（**`json_to_yolo` 只取 `shapes[0]`**） |
| `tool/view.py` | 标签可视化（红色框 + 每图最大置信度） |
| `tool/export.py` | PyTorch → ONNX（opset=11, simplify=True） |
| `tool/pack.py` | 打包（**含 200 MB 限制检查**） |

### Step8 —— 多框感知三阶段自举

| 脚本 | 作用 |
|:---|:---|
| `tool/init.py` | 用 `model_v4` 推理生成多框种子（conf≥0.9，**时序划分**） |
| `tool/train.py` | 训练（支持 `--iou` / `--batch` / `--epochs`；**OOM 分支漏传 iou**） |
| `tool/gen.py` | **多框**伪标签生成（LabelMe JSON + YOLO txt） |
| `tool/merge.py` | 多框感知合并（**种子无条件优先**）+ 时序划分 |
| `tool/converge.py` | 收敛判定（**框级 IoU<0.5，≤5%**） |
| `tool/rebuild.py` | LabelMe JSON → YOLO 数据集（**不含过采样**；与 `labelme_dataset5/code/rebuild.py` 字节相同） |
| `tool/build.py` | 构建最终 LabelMe 数据集（**字典序排序 bug；无置信度过滤**） |
| `tool/view.py` | 颜色编码可视化（**0.95/0.90/0.80 三档**） |

### Step9 —— 多框模型转换与竖棍后处理

| 脚本 | 作用 |
|:---|:---|
| `tool/export.py` | PyTorch → ONNX（opset=12，simplify=False） |
| `tool/eval.py` | CPU 精度评估（100 张，image-scoped 匹配） |
| `tool/visualize.py` | **全量 2827 张三色可视化核验**（含竖棍降级逻辑） |
| **`predict.py`** | **含竖棍三级降级算法的提交脚本（GPU 不可用 ⇒ CPU-only）** |
| `tool/debug_stick.py` | 竖棍问题诊断（分桶统计，`was 196`） |
| `tool/bench_fps.py` | Step7 vs Step9 模型 CPU FPS 对比（**无日志产出**） |
| `tool/pack.py` | 打包（**无 200 MB 检查**） |
