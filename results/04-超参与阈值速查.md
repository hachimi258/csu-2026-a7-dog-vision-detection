### ⚠️ 三处"参数存在但未生效"（全部与超参相关）

| 参数 | 位置 | 问题 |
|:---|:---|:---|
| `--iou 0.9` | Step8 `tool/train.py` | **OOM 重试分支漏传**，全部 15 轮静默回退到 0.7；且 Ultralytics 的 `iou` 是 **NMS 阈值**，不是正样本匹配阈值 |
| `momentum=None` | Step4 `train1.py` | 对 AdamW 传 `None` 是非法值（未硬崩溃），`train1_1.py` 修复为 0.9 |
| `label_smoothing: 0.1` | Step2 `train_exp2.py` | 只写在配置字典里，**从未传给损失函数** ⇒ `Exp2-B` ≡ `Exp2-A` |

## 三、模型 I/O 与预处理约定（B 榜）

| 项 | 值 |
|:---|:---|
| 输入 | 单输入 `[1, 3, H, W]`（H=W=640 或 512） |
| 输出 | 单输出 `[1, 5, N]`，N = 8400（640）或 5376（512） |
| 输出含义 | 5 = `[cx, cy, w, h, confidence]`（单类，无类别分数向量） |
| letterbox | `±0.1` 非对称取整（predict 系）／`floor`（`visualize.py`） |
| 归一化 | BGR→RGB + `/255`，**完全自实现**（不读 `infer_cfg.yml`） |
| 选框规则 | **`argmax(w*h)`** —— 按面积不是按置信度 |
| bug 距离（P2 实测） | Precision 0.9798 / Recall 0.9700 / F1 0.9749（100 张） |

### 三种输出形状分支（全项目统一）

```python
preds = output[0].transpose(1, 0)      # [1, N, 8400] → (8400, N)
if   preds.shape[1] >= 6: bbox_raw, score = preds[:, :4], preds[:, 4] * preds[:, 5]
elif preds.shape[1] == 5: bbox_raw, score = preds[:, :4], preds[:, 4]
else:                     bbox_raw, score = preds[:, :4], preds[:, 4:].max(axis=1)
```

## 四、A 榜关键参数

| 项 | 值 |
|:---|:---|
| 模型 | PP-YOLOE+ CRN-S（`arch: YOLO`），参数量 ~15M |
